План работы над проектом "Акустическая левитация" (примерно 6-8 недель)

**Этап 1: Подготовка и теория (недели 1-2)**
- [ ] Изучение принципов акустической левитации (стоячие волны, узлы давления, акустическая радиационная сила)
- [ ] Сбор информации о существующих установках и их параметрах
- [ ] Расчет параметров для выбранной частоты (длина волны, расстояние между преобразователями)
- [ ] Определение списка необходимых материалов и инструментов
- [ ] Составление теоретической части проекта (конспекты, схемы, формулы)

**Этап 2: Приобретение компонентов (неделя 2-3)**
- [ ] Заказ/покупка ультразвуковых преобразователей и электронных компонентов
- [ ] Получение источника питания и инструментов (при необходимости)
- [ ] Проверка полученных деталей на работоспособность

**Этап 3: Сборка базовой установки (недели 3-4)**
- [ ] Подготовка ультразвуковых преобразователей (очистка, проверка)
- [ ] Сборка простого драйвера на одном MOSFET транзисторе
- [ ] Подключение преобразователей к источнику питания через драйвер
- [ ] Настройка генератора сигнала (начальная частота 40 кГц)
- [ ] Первичная проверка на наличие standing wave (можно использовать мелкие кусочки фольги для визуализации узлов)
- [ ] Первые попытки левитации легких объектов (пенополистирольные шарики)

**Этап 4: Оптимизация и эксперименты (недели 4-5)**
- [ ] Точная настройка частоты для максимального эффекта (поиск резонанса)
- [ ] Эксперименты с разными объектамиlevitation (размер, плотность, форма)
- [ ] Измерение зависимости высоты стабильной левитации от амплитуды сигнала
- [ ] Измерение зависимости устойчивости от частоты (получение резонансной кривой)
- [ ] Тестирование работы при разных расстояниях между преобразователями
- [ ] Фото- и видеофиксирование успешных левитаций
- [ ] Ведение лабораторного журнала с результатами измерений

**Этап 5: Усложнение и дополнительные исследования (неделя 5-6, опционально)**
- [ ] Эксперименты с массивом из 4+ преобразователей для 3D левитации
- [ ] Попытка управления положением объекта через изменение фазы
- [ ] Сравнение работы на разных частотах (25 кГц, 40 кГц, 58 кГц)
- [ ] Исследование влияния ориентированности объекта на левитацию
- [ ] Попытка левитации жидкостей или каплей воды (более сложно)

**Этап 6: Оформление проекта и подготовка к выступлению (недели 6-8)**
- [ ] Систематизация собранных данных и результатов
- [ ] Создание схем установки и графиков зависимостей
- [ ] Подготовка плаката или слайдов для презентации
- [ ] Написание текста выступления (введение, теория, эксперименты, результаты, выводы)
- [ ] Тренировка выступления с демонстрацией или показом видео
- [ ] Подготовка ответов на возможные вопросы от аудитории
- [ ] Финальная проверка всех материалов перед конференциями

**Контрольные точки:**
- К концу недели 2: готов теоретический конспект и список материалов
- К концу недели 3: собрана базовая установка, получены первые признаки левитации
- К концу недели 4: стабильная левитация нескольких типов объектов, начаты измерения
- К концу недели 6: завершен экспериментальный этап, собран полный набор данных
- К концу недели 8: готова презентация и отработано выступление

**Советы по управлению временем:**
- Выделяйте регулярное время на проект (например, несколько раз в неделю по 1-2 часа)
- Фиксируйте все действия и наблюдения в лабораторном журнале
- Не бойтесь неудач – они часть экспериментального процесса
- При проблемах с левитацией сначала проверяйте: выравнивание преобразователей, частоту сигнала, наличие standing wave, достаточность мощности
